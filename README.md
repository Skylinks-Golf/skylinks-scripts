# Skylinks Scripts v2.0

Standalone scripts for Skylinks operations.

## Structure
- **src/airtable**: Scripts for Airtable Automations.
- **src/google-apps**: Google Apps Script logic.
- **src/local**: Local Python/Node/PowerShell tools.

## Mandates
1. **Validation**: Use 'koad skill run global/script_validator.py -- check --path src/.../script.js' before pasting to platform.
2. **Sanctuary Rule**: Developer agents must not touch memory; record discoveries in IMPLEMENTATION.md.
